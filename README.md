# 🀄 마작 주식 & 파생상품 거래 시스템 (Stoke-Mahjong)

스트리머의 작혼 3인 마작(3마) 랭크 점수를 기초 자산으로 하는 실시간 모의 주식 및 파생상품(레버리지, 인버스, 곱버스) 거래 시스템입니다. 치지직(Chzzk) 스트리밍 채팅과 연동되며, OBS 브라우저 소스 오버레이 및 웹 관리자 대시보드를 제공합니다.

## 📈 1. 금융 메커니즘 & 주가 산정 공식

### 주가 산출 공식 (1:1 랭크 포인트 직결 모델)
- **기초 주가**: `current_stock_price = max(100, int(rank_points))`
  - 기본 시작 점수: 2,340pt $\rightarrow$ 기본 주가: **2,340P** (1pt = 1P 완전 일치)
  - 1위 (~+270pt): +270P 상승 (2,610P / 약 +11.5%)
  - 2위 (0pt): 주가 변동 없음 (2,340P)
  - 3위 (~-330pt): -330P 하락 (2,010P / 약 -14.1%)
  - 최저 안전 하한가: 100P (연패/0점/강등 시 파산 방지)
  - 시청자 초기 자본금: 50,000P (약 20~25주 매수 가능)
- **수익률 공식**: `return_pct = (new_price - old_price) / old_price`

### 지원 종목 (Product Types)
1. `1X` (기본주): 기초자산 1배수 수익률 (`return_pct * 1.0`)
2. `2X` (레버리지): 기초자산 2배수 수익률 (`return_pct * 2.0`)
3. `INV` (인버스 / 숏): 기초자산 역방향 1배수 (`return_pct * -1.0`)
4. `2X_INV` (곱버스): 기초자산 역방향 2배수 (`return_pct * -2.0`)

### 마진콜 및 강제 청산 (Liquidation)
- 레버리지(`2X`) 및 인버스(`INV`, `2X_INV`) 종목의 평가 손실률이 **100% 이상**에 도달하거나 잔고 가치가 0 이하로 떨어지는 경우, 포지션이 즉시 전액 강제 청산(`balance = 0`)되며 OBS 오버레이와 채팅창에 경고 알림이 발생합니다.

### 경기 중 거래 동결 (Trading Lock)
- **장 열림 (Market Open)**: 경기 대기실 및 매칭 큐 대기 시간 중 거래 가능.
- **경기 중 거래 마감 (Market Closed)**: 경기 시작 시 거래 락이 활성화되어 매수/매도/지정가/청산이 동결되고, 조회 명령어(`!주식`, `!내정보`, `!주식명령어`)만 허용됩니다.
- **정산 (Settlement)**: 경기 종료 후 스트리머가 순위 및 획득/차감 점수를 입력하면 신규 주가 산출, 레버리지 재조정, 마진콜 청산 집행 후 거래가 자동으로 재개됩니다.

## 💬 2. 채팅 명령어 명세

### 1) 도움말 커맨드
- `!주식명령어` 또는 `!주식도움말`:
```text
📈 [마작 주식 명령어 안내]
• !주식 : 현재 주가, 시장 상태, 전적 확인
• !매수 [종목] [수량/올인] : 매수 체결 (예: !매수 2X 10, !매수 1X 올인)
• !매도 [종목] [수량/전량] : 보유 종목 시장가 매도 (예: !매도 2X 전량)
• !지정가 [매수/매도] [종목] [목표가] [수량] : 목표가 예약 주문
• !내정보 : 잔여 포인트, 보유 포지션 및 수익률 확인
• !청산 [종목/전량] : 보유 포지션 즉시 시장가 전량 정리
* 지원 종목: 1X(기본주), 2X(레버리지), INV(인버스), 2X_INV(곱버스)
```

### 2) 시세 및 계좌 조회
- `!주식` / `!시세`: 현재 주가, 등락폭(▲/▼), 퍼센트, 시장 상태(`[장 열림]` / `[경기 중 - 거래 마감]`), 직전 경기 점수 변동 출력.
- `!내정보` / `!지갑`: 보유 현금 포인트, 총 자산 가치, 보유 포지션별 수량/평단가/수익률(%) 출력.

### 3) 주문 커맨드 & 인라인 가이드
인수가 누락되거나 잘못된 경우 즉시 친절한 사용 가이드를 반환합니다.
- `!매수 [종목] [수량/올인]`: 지정 종목 시장가 매수
  - 가이드: `💡 매수 사용법: !매수 [종목] [수량/올인] (예: !매수 2X 10, !매수 1X 올인)`
- `!매도 [종목] [수량/전량]`: 지정 종목 시장가 매도
  - 가이드: `💡 매도 사용법: !매도 [종목] [수량/전량] (예: !매도 2X 전량, !매도 1X 5)`
- `!지정가 [매수/매도] [종목] [목표가] [수량]`: 목표가 도달 시 자동 체결되는 예약 주문
  - 가이드: `💡 지정가 사용법: !지정가 [매수/매도] [종목] [목표가] [수량] (예: !지정가 매수 1X 300 10)`
- `!청산 [종목/전량]`: 보유 포지션 즉시 시장가 전량 정리
  - 가이드: `💡 청산 사용법: !청산 [종목/전량] (예: !청산 2X, !청산 전량)`

## 🛠️ 3. 스트리머 관리자 API & 대시보드

### 관리자 REST API
1. `POST /api/admin/lock-market`: 거래 동결 토글/설정
2. `POST /api/admin/settle-match`: 경기 결과 정산
   - Body: `{"rank": 1, "point_delta": 270}`
3. `POST /api/admin/grant-points`: 시청자 테스트 포인트 지급/설정
4. `POST /api/chat/command`: 채팅 명령어 HTTP 시뮬레이터

### 웹 화면 및 OBS 오버레이 주소
1. **📈 주가 & 주주 랭킹 전용 오버레이**: `http://localhost:7700/overlay/stock` (또는 `/stock-overlay`)
   - 마작 주가, 등락폭(▲/▼), 국고 풀 잔액(`[🏛️ 국고: 5,000P]`)
   - 시장 상태 뱃지 (`[장 열림]` / `[경기 중 - 거래 마감]`)
   - 상위 주주 랭킹 TOP 3 (🥇, 🥈, 🥉)
   - 실시간 체결 / 채굴 / 배당 / 마진콜 플래시 토스트 알림
2. **🀄 실시간 마작 전적 전용 오버레이**: `http://localhost:7700/overlay/mahjong` (또는 `/tracker-overlay`)
   - 기존 7500 포트 트래커와 100% 동일한 15개 전적 지표 및 점수 표시
3. **🔲 전체 통합 오버레이**: `http://localhost:7700/overlay` (또는 `/?mode=stock`, `/?mode=mahjong`)
4. **⚙️ 스트리머 관리자 패널**: `http://localhost:7700/admin`
   - 치지직 공식 OpenAPI 계정 연동 / 토큰 재발급 (`/api/chzzk/login`)
   - 1클릭 경기 정산 (1위 +270, 2위 0, 3위 -330)
   - 1클릭 거래 마감/재개 토글
   - 실시간 채팅 명령어 시뮬레이션 및 치지직 봇 테스트 메시지 전송

## 🤖 4. 치지직(Chzzk) 오픈 API & 챗봇 안내 연동

- **이중 전송 엔진(Dual Engine)**:
  - 1순위: `.env`의 `CLIENT_ID`, `CLIENT_SECRET` 및 `tokens.json`을 사용한 치지직 공식 Open API (`POST https://openapi.chzzk.naver.com/open/v1/chats/send`)
  - 2순위: 401 만료 시 자동 토큰 갱신(`POST /auth/v1/token`) 및 실시간 웹소켓 세션 자동 폴백
- **자동 안내 발송 조건**:
  - 시청자가 채팅창에서 명령어(`!매수`, `!매도`, `!지정가`, `!청산`, `!채굴`, `!주식`, `!내정보` 등)를 실행할 때
  - 관리자 패널 콘솔에서 명령어가 실행될 때
  - 경기 종료 후 순위 정산 및 마진콜 청산 발생 시
- **메시지 분할 전송**: 치지직 Open API의 100자 글자 수 제한을 준수하도록 줄바꿈 및 단어 단위 자동 청킹 분할 발송
