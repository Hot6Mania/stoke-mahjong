🔗 치지직 공식 계정 연동 / 재인증 (1초 연동)
📌 방법 1. 인증 코드(code 또는 주소창 전체 URL)로 토큰 즉시 자동 발급

위 [치지직 공식 계정 연동] 승인 후 브라우저 주소창에 나타난 URL(예: http://localhost:7700/callback?code=XXXXX...) 또는 code= 뒤의 인증 코드만 붙여넣으시면 시스템이 즉시 Access Token을 발급받아 등록합니다.

📌 방법 2. Access Token & Refresh Token 직접 입력

개발자 센터 또는 외부 도구(Postman 등)를 통해 발급받은 토큰이 있는 경우 직접 등록합니다.

💡 안내: 시청자가 방송 채팅창에 명령어를 입력하거나 위 시뮬레이터에서 명령어를 실행할 때마다, 치지직 공식 Open API(우선) 및 웹소켓 세션을 통해 안내 채팅이 실시간으로 발송됩니다. (글자 수 제한 100자 이내 자동 분할 및 쿨타임 준수)

🎁 치지직 후원(DONATION) 1:100 포인트 자동 충전 1원 = 100P 충전

치지직 Session 소켓 또는 Webhook에서 DONATION 이벤트가 감지되면, 후원 금액(payAmount)에 대해 1:100 비율(예: 1,000원 후원 시 100,000P)로 시청자 지갑에 즉시 자동 충전됩니다.
🛡️ 중복 후원 방지(Idempotency 검증), 데이터 이상값 차단, 충전 직전 DB 자동 핫 백업이 수행되어 데이터가 안전하게 보호됩니다.
